NetWatch Windows v1.4.0 便携版

一、启动
1. 请先完整解压压缩包，不要直接在压缩包内运行。
2. 双击 Start-Portable.cmd。
3. 程序会启动 NetWatch，并打开监控页面。

二、本版本主要功能
- 三栏网络监控总览，展示真实采集到的设备、流量、CPU、内存、告警和接口状态数据。
- 网络拓扑会根据设备数量自动排列并适配当前页面，打开后可一眼看到全部节点。
- 拓扑节点可以拖动，松开后位置自动保存；也可以点击“自动排列”恢复布局。
- 设备管理按设备名称排序，每页显示 10 台，可以翻页。

三、从旧版本升级
1. 先退出正在运行的旧版 NetWatch。
2. 备份旧版本目录中的 Data 文件夹。
3. 解压本版本后，将旧版本的 Data 文件夹复制到新版本目录并覆盖同名目录。
4. 不要删除旧版目录，确认新版本设备和历史数据正常后再自行归档。

四、安全提示
本程序默认用于可信的局域网管理环境，不提供账户登录功能。请勿直接暴露到互联网。
